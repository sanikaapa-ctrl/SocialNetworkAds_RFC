# 📱 Social Network Ads Prediction Using Random Forest Classifier

## 📌 Project Overview

This project uses Machine Learning to predict whether a user will purchase a product after viewing an advertisement on a social media platform.

The project implements a **Random Forest Classifier (RFC)** to analyze user demographic information such as Age and Estimated Salary and predict purchasing behavior.

## 🎯 Project Objectives

- Analyze social network advertisement data.
- Perform Exploratory Data Analysis (EDA).
- Preprocess and clean the dataset.
- Apply feature selection and feature scaling.
- Build a Random Forest Classification model.
- Predict whether a user will purchase a product.
- Evaluate model performance using classification metrics.

## 📂 Dataset Information

The project uses the Social Network Ads dataset.

| Feature | Description |
|---|---|
| User ID | Unique user identification |
| Gender | User's gender |
| Age | User's age |
| EstimatedSalary | Estimated annual salary |
| Purchased | Target variable (0 or 1) |

**Target Variable:**
- `0` – User did not purchase the product.
- `1` – User purchased the product.
